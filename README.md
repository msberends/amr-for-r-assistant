# AMR for R Assistant (Helper Repo)

<https://chat.amr-for-r.org>

This repo provides these things:
* `index.html` is a redirect to <https://amr-for-r.org/articles/chat.html>, so that <https://chat.amr-for-r.org> works (via GitHub Pages in this repo). That page opens Claude or ChatGPT with instructions to answer from the official documentation of the installed version of the AMR package.
* `CNAME` was automatically created by GitHub Pages to allow the redirect
* `latest_training_data.txt` contains the package documentation that the former custom GPT in ChatGPT read before its initial response. It is no longer updated.
